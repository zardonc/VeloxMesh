<objective>
Add capability and routing preflight for normalized tool protocol requirements. Every routing branch must prove that the selected real provider and model support the requested definitions, choice mode, stream mode, assistant call history, and tool results before any upstream I/O; incompatible explicit requests fail clearly, automatic selection filters them, and Fusion refuses the protocol rather than attempting identity reconstruction.
</objective>
