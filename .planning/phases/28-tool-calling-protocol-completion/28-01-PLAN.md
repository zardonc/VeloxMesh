<objective>
Freeze the normalized public tool-calling contract and enforce it at the HTTP boundary. The result is a typed, immutable request representation that preserves omitted versus explicit tool_choice values, validates conversation correlation before routing, and gives callers stable 400-class protocol errors without invoking the gateway service or any provider.
</objective>

</context>
